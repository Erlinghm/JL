# Solution: Use the Agricultural Marketplace design system

Use the design system from `DESIGN.md` when implementing or reviewing UI work.

## Visual direction

- Use a modern agricultural aesthetic rather than a clinical tech-heavy look.
- Use Forest Green for brand-heavy surfaces, navigation, and primary headings.
- Use Terra Cotta only for high-visibility call-to-action elements.
- Use cream and slate neutrals instead of pure white and pure black.
- Use watercolor textures as atmospheric accents behind crisp UI components.
- Use parchment, linen, and stone neutrals for softer marketplace surfaces.

## Type and layout

- Use Manrope for headings, body text, labels, and metadata.
- Keep a strong typographic hierarchy with heavier, tighter headlines.
- Use generous body line-height for land descriptions and agreement-heavy
  content.
- Center desktop content in a 1280px max-width container with a fixed grid.
- Use a fluid single-column layout with 16px side margins on mobile.

## Components

- Use rounded buttons, inputs, and cards.
- Keep card shadows soft and ambient rather than heavy.
- Use white cards with 24px padding for core marketplace content.
- Use chips or badges for land categories such as `Dyrket mark` and `Beite`.
- Use subtle dividers for dense property detail lists.
- Use sticky top navigation with a clear Terra Cotta active state when the
  layout includes a top nav.
- Prefer Norwegian call-to-action labels that match local marketplace intent,
  such as `Bli utleier`, over generic startup language.
