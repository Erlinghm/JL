# Problem: The marketplace needs a consistent visual system

The project needs UI decisions that feel appropriate for a Norwegian farmland
marketplace rather than a generic SaaS product.

## Context

`DESIGN.md` defines a design system named "Agricultural Marketplace System."
`comprehensive_design_guidelines_design.md` describes the same direction for
LandLeie with concrete palette, component, and Norwegian-language guidance.

## Product tension

The UI must balance:

- Traditional land ownership and modern digital efficiency.
- High-end professionalism and warm accessibility.
- Structured marketplace data and organic agricultural atmosphere.
- Desktop dashboard consistency and mobile single-column usability.
