# Problem: BankID app users can fail activation or login

The scraped BankID notes document common user-facing problems with BankID app
activation, push notifications, biometrics, and device changes.

## Common user issues

- The user does not know how to get or activate the BankID app.
- Push notifications do not appear during login.
- Activation fails with a misleading contact-information error.
- The user has an old app version or unsupported device.
- The app is locked after repeated failed login attempts.
- The user moved to a new phone.
